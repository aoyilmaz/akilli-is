## 2026-02-28 - Centralized Accessible Icons and Cursors
**Learning:** In PyQt applications, tooltips on icon-only buttons provide visual help but do not reliably announce their purpose to screen readers. Applying `.setAccessibleName(tooltip)` ensures these elements are properly described to assistive technologies. Additionally, visually hinting interactivity by adding `.setCursor(Qt.CursorShape.PointingHandCursor)` gives users clear feedback that the element is clickable. Consolidating this in a shared component (`ui/components/action_buttons.py`) ensures application-wide consistency for these UI patterns.
**Action:** When defining reusable icon-only action button components in PyQt, always set both `.setToolTip()` for visual users and `.setAccessibleName()` for screen reader users, and enforce `.setCursor(Qt.CursorShape.PointingHandCursor)` on interactive elements.
